# 🛍️ XaridGo

### 🛒 Zamonaviy onlayn savdo platformasi

**XaridGo** — turli xil mahsulotlarni internet orqali topish, ko‘rish va xarid qilish uchun mo‘ljallangan zamonaviy onlayn savdo veb-sayti.

---

## 🌐 Loyiha haqida

XaridGo foydalanuvchilarga mahsulotlar bilan qulay va sodda tarzda tanishish hamda kerakli mahsulotlarni topish imkonini beruvchi elektron savdo platformasidir.

Sayt zamonaviy, qulay va foydalanishga oson interfeys asosida ishlab chiqilgan.

---

## 🚀 Asosiy imkoniyatlar

- 🛍️ Turli xil mahsulotlar
- 🔎 Mahsulotlarni izlash
- 📂 Mahsulotlarni kategoriyalar bo‘yicha ko‘rish
- 👤 Foydalanuvchi profili
- 🛒 Onlayn xarid qilish
- 📦 Buyurtmalarni ko‘rish
- 🔐 Foydalanuvchi autentifikatsiyasi
- ⚙️ Admin boshqaruvi
